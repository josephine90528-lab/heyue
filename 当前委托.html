一、 多头仓位条件单（平多 / Close Long）

用于平掉现有的多头持仓（平仓动作：卖出 / Sell）：

1、市价止盈 / 平多

   · 触发条件：最新价格/标记价格 ≥ 触发价（如 ≥ 90.00）

   · 执行方式：以市价 (Market) 立即卖出平多，快速锁定利润。

2、限价止盈 / 平多

   · 触发条件：最新价格/标记价格 ≥ 触发价（如  ≥  91.00）

   · 执行方式：触发后，以设定的限价挂单卖出平多（如挂单 $115.00 USDT），追求更优卖价。

3、市价止损 / 平多

   · 触发条件：最新价格/标记价格 ≤ 触发价（如 ≤ 86.00）

   · 执行方式：以市价立即卖出平多，迅速止损截断亏损。

4、限价止损 / 平多

   · 触发条件：最新价格/标记价格 ≤ 触发价（如 ≤ 84.00）

   · 执行方式：触发后，以设定的限价挂单卖出平多（如挂单 85.00）。


二、 空头仓位条件单（平空 / Close Short）

用于平掉现有的空头持仓（平仓动作：买入 / Buy）：

5、市价止盈 / 平空

   · 触发条件：最新价格/标记价格 ≤ 触发价（如价格下跌至 ≤ 75.00 时）

   · 执行方式：以市价 (Market) 立即买入平空，快速锁定空头利润。

6、限价止盈 / 平空

   · 触发条件：最新价格/标记价格 ≤ 触发价（如价格下跌至 ≤  75.00 时）

   · 执行方式：触发后，以设定的限价挂单买入平空（如指定以较低的 $72.00挂单买入平仓）。

7、市价止损 / 平空

   · 触发条件：最新价格/标记价格 ≥ 触发价（如价格反弹上涨至 ≥ 95.00 时）

   · 执行方式：以市价立即买入平空，防止价格继续上涨导致空头亏损扩大甚至爆仓。

8、限价止损 / 平空

   · 触发条件：最新价格/标记价格 ≥ 触发价（如价格反弹上涨至 ≥ 95.00 时）

   · 执行方式：触发后，以设定的限价挂单买入平空（如指定以 $96.00挂单买入平仓）。
